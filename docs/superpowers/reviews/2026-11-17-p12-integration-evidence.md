## Authenticated OpenRouter measurement

Use a new inference key on a funded fixture-only account with no BYOK routes. Require a finite, non-resetting USD spend cap that includes BYOK and is at or below the approved budget. Choose the maximum requests and candidates before starting. Keep the key in the launching shell through the operator's secret manager. The command uses the committed synthetic inputs and checkpoints its dated report under ignored `artifacts/self-hosting/live-ai/`. Keep raw headings and vectors in that private report. Record reviewed aggregates and outcome references in the release evidence.

```text
npm run measure:ai -- --manifest-only
npm run measure:ai -- --max-usd <USD> --max-requests <count> --max-candidates <count>
npm run verify -- --phase 6 --image feedbackland:ci --artifacts artifacts/self-hosting --calibration-report <private-report>
```

Catalogue quotes determine evaluation order. Compare every eligible candidate on the mean observed cost of title plus moderation for the same 20 accepted text posts. The report records exclusions and treats vision qualification and price evidence separately. Independent reviewers assess the retained headings for faithfulness, safety and language, and approve the held-out labels before the paid run. A changed model or prompt requires a newly reviewed validation set alongside these regression cases. Record the selected model's actual vision diagnostic, maximum shape results, served model and usage, 768-dimensional embed check, and post-write cost per 100 text posts. An estimate based on observed embedding tokens and listed per-token and per-request prices is labeled in the report. Missing costs stay unknown.

Measure pair distances in local pgvector and apply the midpoint to the selected default. After rebuilding the release candidate, run the cumulative gate with the private report to verify related and unrelated pairs on both query surfaces. The verification summary records the assertion counts without copying the report. Current defaults remain provisional until the reviewed run and exact-image verification are recorded.
